# Персоналия

Сайт компании «Персоналия» — организация временного персонала на мероприятиях под ключ (Москва и регионы).

## Структура

- `index.html` — главная
- `services.html`, `service.html` — услуги и карточка услуги
- `about.html` — о компании
- `cases.html` — кейсы
- `contacts.html` — контакты
- `thanks.html` — страница «спасибо» после отправки формы
- `style.css`, `script.js` — стили и скрипты
- `assets/` — изображения

## Деплой

Сайт задеплоен через GitHub Pages из ветки `main` (корень).
